A 4 KB Python chess engine in a single 4,026-byte main.py: alpha-beta search with PVS, quiescence, transposition table and a fixed node budget (deterministic, no clock). Local practice Elo ~1,365 against the house gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8000 python3 main.py
```
